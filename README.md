# CSV & Excel Manager Pro

A professional desktop application for merging and splitting CSV and Excel files with an intuitive interface.

![Version](https://img.shields.io/badge/version-1.0.0-brightgreen)
![Platform](https://img.shields.io/badge/platform-Windows%20%7C%20macOS-blue)

## Features

### File Merging
- Merge multiple CSV and Excel files into one
- Support for CSV (.csv) and Excel (.xlsx, .xls, .xlsm) formats
- Drag & drop support for easy file selection
- Keep or remove headers
- Skip empty rows automatically
- Remove duplicate rows
- Custom encoding and delimiter options
- Real-time file preview

### File Splitting
- Split large CSV/Excel files into smaller chunks
- Define custom rows per file
- Keep headers in all split files
- Convert between formats (CSV ↔ Excel)
- Preview before splitting
- Automatic file naming with timestamps

### User Interface
- Modern dark theme with lemon-lime accents
- Responsive design
- Professional typography (Segoe UI)
- Progress indicators for long operations
- Tab-based navigation

### Windows
1. Download the `.exe` file
2. Double-click to run
3. No installation required - portable application

### macOS
1. Download the `.app` file
2. Move to Applications folder
3. Right-click and select "Open" (first time only)

## How to Use

### Merging Files
1. Open the **Merge Files** tab
2. Drag & drop files or click "Add Files"
3. Configure options (headers, duplicates, encoding)
4. Click "MERGE FILES"
5. Choose where to save the merged file

### Splitting Files
1. Open the **Split File** tab
2. Drag & drop a file or click "Select File"
3. Set rows per file
4. Configure options (headers, format, encoding)
5. Click "SPLIT FILE"
6. Choose output directory

## Supported Formats

**Input**: CSV, Excel (.xlsx, .xls, .xlsm)
**Output**: CSV, Excel (.xlsx)
